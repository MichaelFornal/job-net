# Patterns that must not appear anywhere in this repo or its history.
# One extended-regex per line, matched case-insensitively.  '#' comments and
# blank lines are ignored.
#
# This file is generic on purpose.  A denylist of real names, employers and
# addresses would PUBLISH exactly what it exists to keep out -- so anything
# identity-specific belongs in `tools/denylist.local.txt`, which is gitignored
# and read automatically when present.  Keep it that way.

sk-(ant-)?[A-Za-z0-9_-]{20,}
xox[baprs]-[A-Za-z0-9-]{10,}
glpat-[A-Za-z0-9_-]{20,}

Authorization:[[:space:]]*Bearer[[:space:]]+[A-Za-z0-9._-]{12,}
(password|passwd|secret|api[_-]?key)[[:space:]]*[=:][[:space:]]*["'][^"']{8,}["']

# --- machine paths (leak the account name of whoever built the tree) ---
/Users/[a-z]

# --- contact details.  A pipeline that reads job postings has no business
# --- carrying a personal phone number or a home address.
# NOTE: no '#' inside a pattern -- comment stripping cuts the line there and
# leaves an unbalanced group, which makes grep abort.  See the validator below.
\(?[0-9]{3}\)?[ .-][0-9]{3}[ .-][0-9]{4}
[0-9]{1,5} [A-Z][a-z]+ (St|Street|Ave|Avenue|Rd|Road|Ln|Lane|Dr|Drive) (Apt|Unit)\b
